# Project vision

Single-player Windows 2D top-down tile sandbox RPG inspired by survival, lordship,
talent awakening and cultivation fantasy. A real game with engine-enforced rules,
not chatbot storytelling. No mandatory linear quest chain.

Persistent World Blueprint + Independent Runs + Evolving World.
Geography, fixed landmarks, history and established AI content persist across runs.
Characters, inventories, monsters, chests, resources and quests reset per run.
Old runs remain available. Normal and permadeath share a blueprint; death behavior
belongs to Milestone 02.

AI creates structured content asynchronously. Existing local gameplay must work
without AI, network or Python. Unsupported ideas are retained as pending capability,
with future mechanic proposals, tests and explicit approval before integration.
Never let generated content execute arbitrary code.

First deliver a maintainable, testable offline foundation. Placeholder visuals are
acceptable. Combat, elaborate talents, quests and pets are outside Milestone 01.
