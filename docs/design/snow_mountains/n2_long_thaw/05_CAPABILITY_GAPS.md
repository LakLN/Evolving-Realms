# Capability gaps

Only gaps required by the designed content are listed.

| Capability | Why N2 needs it | Safe interim behavior |
| --- | --- | --- |
| Run-local authored route/terrain overlay | Water-course choices should open/close fords and redirect visible channels | End the first tranche at a recorded recommendation; do not change collision or claim the river moved |
| Receipt-driven landmark/art variants | Weirs, floodgates and channel surfaces need state-aligned visuals | Keep baseline visuals and report the intended state in text |
| Cross-location evidence condition | The measured spill branch requires multiple independent observations | Use explicit evidence items only if inventory UX is accepted; otherwise defer the branch |
| Deterministic local season/high-thaw phase | Market activity, fish runs and ford risk should vary without reload rerolls | Ship a static baseline climate first; do not simulate seasons through random events |
| Creature observation → site consequence bridge | Reedhorn/sluiceback choices should affect later tracks, sheds and route clues | Prototype tracks as locations independent of live creature state |
| Conversational NPC and seasonal camp presence | Later presentation benefits from individuals and community choices | Environmental evidence and documents carry tranche-one narrative |
| State-conditioned spawn/resource tables | Water-course branches should alter fish, reeds and ambush locations | Keep encounters/resources unchanged until state filters are validated |
| Interior transition authoring | Gatehouse/cellar/underflow interiors need explicit scene travel | Keep entrances sealed/non-interactive; never paint a playable doorway prematurely |

Not required: multiplayer, global fluid simulation, public services, Python runtime, a universal quest subsystem, or a new save database schema.
