# Implementation plan

This is a staged handoff based on the completed content design, not an authorization to activate it.

## Stage 1 — evidence vertical slice

Create a new append-only authored land/layout version with only Thawgate, Weir Five and one safe return loop at first. Install the isolated draft pack in disposable Worlds. Implement the five evidence locations and recommendation-only terminal choices using current handlers. Tests: import, pack validation, deterministic layout/connectivity, start certification, interaction refusal/exclusivity and save/load.

Exit criterion: a player can enter, navigate without placeholders obscuring routes, gather evidence in different orders and record one recommendation. No text claims water or collision changed.

## Stage 2 — full seamless topology and ecology

Author all seven outdoor areas, the main circuit and inner loop. Add approved static resource/creature definitions and fixed homes. Validate reverse-order generation, connector reachability, no cross-land ecology leakage and safe starts. Do not add interiors yet.

## Stage 3 — environmental consequence capability

Design and approve a bounded Run-local terrain/route overlay keyed by the exclusive Weir Five receipt. It must resolve rendering, collision, path connectivity, spawn/resource filters and save/load from one authoritative state. Add state-specific art only after the handler exists.

## Stage 4 — deeper chains and interiors

Add cross-location evidence support or an approved evidence-item UX, then implement the measured-spill branch. Author gatehouse/cellar/underflow interiors through explicit transitions. Add creature observation consequences. Conversational seasonal NPCs remain optional and require their own approved subsystem.

## Stage 5 — production and release gates

Complete art/audio, native viewport readability review, balance pass, spoiler-safe playtest and old-save checks. Present package through propose → validate → explicit approval → activate. Bind only to an explicitly chosen World/version. Never rewrite an established land record.

## First technical task

Build an engine-side disposable validator test for `content/drafts/snow_mountains/long_thaw/content_pack.json`, then decide whether the first map slice uses a new layout designer record or a broader approved land-package workflow. Do not begin art production until topology and state boundaries are accepted.
