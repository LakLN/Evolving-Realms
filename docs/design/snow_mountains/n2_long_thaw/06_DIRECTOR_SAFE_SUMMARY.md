# The Long Thaw — director-safe summary

This proposal adds one lower-elevation Snow Mountains cluster built around seasonal meltwater, braided rivers, alder wetlands, short grass seasons and old communal waterworks. It is geographically and visually distinct from Hushed Crown and leaves room for many future Snow Mountains lands.

The proposed land contains seven seamless outdoor areas, two meaningful route circuits and optional small interiors. Exploration emphasizes reading water, animal traces, flood marks and repair history. Some locations exist for navigation, ecology or atmosphere rather than quests.

The content package includes a major environmental investigation, two medium discovery chains, minor observations, rare events and several per-Run decisions. Outcomes emphasize access, survival knowledge and regional resources rather than a mandatory main story or oversized legendary reward.

The ecology is built around new wetland producers, fish, a neutral ecosystem engineer, migratory grazers and localized predators. Creature signs provide navigation and choice; not every encounter is automatically hostile.

Technical scope proposed for implementation:

- new append-only land/layout/content versions, never edits to Hushed Crown;
- existing location interaction and world-event patterns for the first evidence tranche;
- later bounded capabilities for route state, landmark variants, seasonal conditions and creature-linked consequences;
- deterministic, Run-local changes with old Runs and personal saves preserved;
- no automatic binding or publication before explicit approval and playtest.

No map, art or gameplay code is included in N2. Draft JSON is isolated from active layouts and exists only to make the next implementation pass concrete.
